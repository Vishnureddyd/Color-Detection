About Webcam Color Detection

Real-time Color Capture

This app uses your webcam to stream real-time video. When you click on a specific spot in the video, it captures the pixel color at that point.

RGB and Hex Extraction

The RGB values from the selected pixel are used to generate a hexadecimal color code. This data is displayed live on the video frame.

Color Name Matching

The application compares the extracted color to a CSV of predefined color names to display the closest matching color name and its hex code.
