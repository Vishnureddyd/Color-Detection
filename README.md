# Color Detection

## Project Description
This project is a **Python-based application** that identifies and displays the name and RGB values of colors from images. Users can either use their webcam or upload images to detect colors in real-time.

## Features
- Detect colors from images or live video feed.
- Display color name, hex code, and RGB values.
- User-friendly interface built with Python libraries.

## Domain
This project falls under **Computer Vision / Image Processing**. It can be extended to applications in **IoT, Embedded Systems, or Agriculture** for object color recognition.
